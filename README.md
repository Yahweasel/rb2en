# Royal Blood II English patch

This is a patch of Royal Blood II (Gemfire II) into English, using
[mecha-translation-builder](https://github.com/Yahweasel/mecha-translation-builder).
Note that the per se translation was AI generated and has limitations; it is
hopefully sufficient to play the game (though it is currently in a very early
stage, and may not even be sufficient!).

I only have and can only patch a single version of Royal Blood II. I have no
idea if multiple versions exist. My version has the following sha1sums:

```
e77d2ff484f765a33d20e345361d00c604b17dfa  RB2.exe
241225034b3b6904f99128ff53f9c32082d33cfe  Message.rb2
8d85e5505935c7494a9dbe8c68220920ebeeaba6  SceDat1.rb2
d7ce39d5314d09630007a57b7b357ecb8691f8b2  SceDat2.rb2
```

This repository is not usable without a full copy of Royal Blood II. The author
of this repository purchased a boxed copy from Japan and would recommend that
you do the same if you wish to play it. Royal Blood II uses copy protection,
and these English patches do not circumvent the copy protection (i.e., you
still need a valid copy of the Japanese original to play).


## Patches

You will need a Shift-JIS installation of Windows and a copy of Royal Blood II.
It's possible that the game would work on an English installation of Windows
after patching, but I haven't tested this. Before patching, install the game as
usual.

There are four files that need to be changed: `RB2.exe`, `Message.rb2`,
`SceDat1.rb2`, and `SceDat2.rb2`. Except for `RB2.exe`, each is distributed as
an IPS-format patch file in the [patch](patch) directory. `Message.rb2` was
completely rebuilt and cannot simply be patched, so the entire file is in
[patch/Message.rb2](patch/Message.rb2).

Apply the IPS patches with your favorite IPS patching tool, e.g.
[FLIPS](https://github.com/Alcaro/Flips). Simply replace `Message.rb2` with the
version in this repository.

### Limitations

This is mostly a *binary patch*, which means that strings can only be replaced
with shorter strings. Written Japanese is much more semantically dense than
English is, so most of the translation is very terse, and in some cases hard to
understand. Luckily, most of the *plot* strings are stored in `Message.rb2`,
which the author of this patch reverse engineered, so those strings are
(mostly) complete. The user interface strings are not in `Message.rb2` and will
take some getting used to.

It is possible, and indeed likely, that I have missed strings. If you find an
untranslated string, please post a screenshot as an issue in this repository.
